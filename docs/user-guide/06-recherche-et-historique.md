# Rechercher un morceau et consulter l’historique

La Recherche permet de retrouver rapidement un morceau. L’Historique permet de consulter les lectures précédentes du Lecteur principal et du DJ.

## Rechercher sur téléphone

1. touchez l’icône **Recherche** dans la barre inférieure ;
2. saisissez tout ou partie du titre ;
3. consultez les résultats ;
4. touchez un morceau pour le lancer.

Après le lancement, la recherche se ferme afin de rendre la playlist de nouveau accessible.

## Rechercher sur tablette

Sur tablette, la recherche fonctionne comme un filtre du panneau actif :

- depuis la Bibliothèque, elle filtre les morceaux de la Bibliothèque ;
- depuis une playlist, elle filtre les morceaux de cette playlist.

La recherche ne remplace pas définitivement la destination du panneau droit.

## Quels titres sont recherchés ?

La recherche utilise le titre affiché dans MusiMio. Si vous avez renommé un morceau, son titre personnalisé est utilisé en priorité.

La recherche porte sur les morceaux jouables connus de la Bibliothèque. Un fichier non importé ou inaccessible peut ne pas apparaître.

## Conseils de recherche

- Commencez par quelques lettres distinctives.
- Essayez sans ponctuation si le titre contient des signes particuliers.
- Recherchez le titre personnalisé plutôt que l’ancien nom du fichier.
- Si le morceau vient d’être importé, attendez la fin de l’actualisation de la Bibliothèque.

## Aucun résultat

Vérifiez successivement :

1. que le morceau apparaît dans Songs ;
2. que la Bibliothèque n’est pas en cours de premier chargement ;
3. que vous n’êtes pas dans une recherche limitée à une playlist qui ne contient pas ce morceau ;
4. que le titre saisi correspond au titre affiché ;
5. qu’une actualisation de la Bibliothèque n’est pas nécessaire.

## Ouvrir l’Historique

1. ouvrez **Paramètres / Plus** ;
2. choisissez **Historique**.

Les événements sont regroupés par date.

## Filtrer l’Historique

Trois filtres sont disponibles :

- **Tout** : toutes les lectures enregistrées ;
- **Backing** : morceaux du Lecteur principal ;
- **DJ** : lectures du mode DJ.

L’option **Date/heure** permet d’afficher ou de masquer les horaires détaillés.

## Partager l’Historique

1. choisissez le filtre souhaité ;
2. appuyez sur **Partager** ;
3. sélectionnez l’application de destination dans le menu Android.

Le partage produit une liste textuelle contenant la date, la source et le titre des événements affichés.

## Vider l’Historique

1. appuyez sur **Vider** ;
2. lisez la confirmation ;
3. choisissez **Effacer**.

Cette action est irréversible. Elle efface l’historique de lecture, pas les morceaux ni les playlists.

## À savoir

- L’Historique ne remplace pas une playlist ni une sauvegarde.
- Effacer l’Historique ne remet pas forcément à zéro les indicateurs « joué » d’une playlist.
- Un événement peut afficher un ancien titre s’il a été enregistré avant le renommage du morceau.
