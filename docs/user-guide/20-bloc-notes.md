# Utiliser le Bloc-notes

Le Bloc-notes conserve des textes libres dans Stage Music Player : rappels de scène, annonces, réglages matériels, programme ou consignes liées à une playlist.

## Ouvrir le Bloc-notes

Ouvrez **Bloc Notes** depuis le menu principal. Sur tablette, il peut aussi apparaître dans le menu des raccourcis de scène.

## Créer une note

1. ouvrez **Mes notes** ;
2. appuyez sur `+` ;
3. saisissez un titre ;
4. écrivez le contenu ;
5. validez avec **OK**.

Si le titre est vide, la note peut être affichée comme **Sans titre**. Un titre court et explicite reste préférable en situation de scène.

## Modifier ou renommer

1. ouvrez le menu de la note ;
2. choisissez **Renommer / éditer** ;
3. modifiez le titre ou le texte ;
4. validez.

## Associer une note à une playlist

1. ouvrez le menu de la note ;
2. choisissez **Attribuer à une playlist** ;
3. sélectionnez la playlist concernée.

Cette association aide à retrouver une consigne dans le contexte du programme. Elle ne transforme pas la note en paroles synchronisées ni en texte défilant.

## Partager

Vous pouvez partager la note ouverte ou l’ensemble des notes au moyen du menu de partage Android. Le contenu est envoyé comme texte vers l’application choisie.

Le partage ne constitue pas une sauvegarde automatique : vérifiez le message ou le fichier produit par l’application destinataire.

## Supprimer une note

Ouvrez le menu de la note, choisissez **Supprimer**, puis confirmez si l’application le demande. La suppression retire la note de Stage Music Player.

## Différence avec les autres textes

- **Note** : texte libre de préparation ou de scène.
- **Paroles** : texte associé à un morceau, éventuellement synchronisé.
- **Texte défilant** : prompteur autonome avec défilement.
- **Note Timeline** : message placé à un instant précis du morceau.

## Sauvegarde et synchronisation

Ne supposez pas que les notes sont incluses dans tous les exports `.smp` ou dans SMP Sync : le transfert des notes par SMP Sync est annoncé comme une évolution future. Pour une note importante, utilisez également **Partager** vers un emplacement externe et vérifiez le résultat.

## Problèmes courants

### Aucune playlist n’est proposée

Créez d’abord une playlist, puis recommencez l’attribution.

### Une note n’apparaît pas dans les paroles

C’est normal : les notes et les paroles sont deux contenus distincts.

### Une note importante doit être transférée

Partagez-la explicitement sous forme de texte. Ne comptez pas sur SMP Sync pour ce transfert dans la version actuelle.
