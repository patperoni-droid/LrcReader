# Comprendre la Bibliothèque

La Bibliothèque est le point de départ pour préparer vos morceaux. Elle permet de consulter les morceaux live, parcourir certains fichiers, importer du contenu, créer des familles de versions et gérer les textes défilants.

## Ouvrir la Bibliothèque

- Sur téléphone, touchez **Bibliothèque** dans la barre inférieure.
- Sur tablette, ouvrez **Bibliothèque** dans le menu du cockpit. La playlist reste visible à gauche.

## Les vues de la Bibliothèque

Selon la disposition de l’écran, la Bibliothèque propose plusieurs vues :

### Songs

Affiche les morceaux live préparés par Stage Music Player. Ce sont les éléments à privilégier pour les playlists et la lecture sur scène.

Un morceau live peut contenir l’audio, les paroles, les accords, les réglages et d’autres données associées.

### Fichiers

Permet de parcourir les fichiers accessibles dans le stockage autorisé. Cette vue sert surtout à retrouver ou convertir un contenu qui n’est pas encore un morceau live.

### Lists

Donne accès aux playlists depuis la Bibliothèque.

### Textes défilants

Affiche le catalogue des textes autonomes sans audio. Consultez [Créer et utiliser des textes défilants](12-textes-defilants.md).

### LEVELS

Ouvre l’espace de préparation manuelle des niveaux sonores. Chaque morceau affiche son réglage en décibels et peut être écouté depuis plusieurs passages avant ajustement. Consultez [Préparer les niveaux des morceaux avec LEVELS](13-levels-et-niveaux-des-morceaux.md).

## Morceau live, fichier source et playlist

Ces trois notions sont différentes :

- le **fichier source** est le fichier que vous avez choisi sur l’appareil ;
- le **morceau live** est la copie de travail préparée par Stage Music Player ;
- la **playlist** contient une référence vers ce morceau live.

Ajouter un morceau à plusieurs playlists ne crée pas plusieurs copies de l’audio.

## Ouvrir ou écouter un morceau

Dans la vue Songs :

- touchez la ligne ou le titre pour lancer le morceau par le parcours normal ;
- utilisez le bouton de lecture de la ligne lorsqu’il est proposé pour une écoute rapide ;
- ouvrez le menu du morceau pour accéder aux actions supplémentaires.

Sur tablette, toucher la ligne principale lance le morceau puis revient généralement vers **Playlist | Paroles**. Le petit bouton de lecture de la ligne peut servir à une écoute locale sans quitter la Bibliothèque.

## Sélectionner plusieurs éléments

La sélection multiple permet d’effectuer une action sur plusieurs morceaux :

1. activez la sélection sur un premier morceau ;
2. choisissez les autres morceaux ;
3. utilisez la barre d’actions pour **Attribuer**, **Copier**, **Déplacer** ou **Supprimer** ;
4. vérifiez attentivement le résumé avant une suppression.

L’ordre de sélection peut être conservé lors de l’ajout à une playlist.

## Créer une famille de versions

Une famille regroupe plusieurs morceaux live qui représentent des versions ou des choix proches.

Exemples :

- version normale, courte et acoustique ;
- tonalité normale et version abaissée ;
- plusieurs morceaux possibles pour le même moment du concert.

Pour créer une famille :

1. sélectionnez au moins deux morceaux dans Songs ;
2. choisissez **Créer famille de versions** ;
3. vérifiez le nom proposé ;
4. validez la famille.

La famille ne fusionne pas les fichiers. Chaque choix reste un vrai morceau live indépendant.

## Variantes Arrangement

Une variante Arrangement apparaît comme un morceau distinct, généralement signalé par le badge **ARR**. Elle peut être lue, modifiée, ajoutée à une playlist et partagée.

Elle dépend toutefois de l’audio de son morceau parent. Supprimer le parent de la Bibliothèque supprime également ses variantes après confirmation.

## Renommer un morceau

L’action **Renommer** change le titre affiché dans Stage Music Player. Elle ne renomme pas automatiquement le fichier audio d’origine.

Le nouveau titre doit rester visible après la lecture, le changement d’écran et le redémarrage de l’application.

## Actualiser la Bibliothèque

Utilisez l’action de réanalyse lorsque :

- un import vient de se terminer mais n’apparaît pas ;
- le contenu d’un dossier autorisé a changé ;
- vous avez rétabli une autorisation Android.

Pendant l’analyse, les morceaux déjà connus peuvent rester visibles. Cela permet de continuer à accéder rapidement au contenu préparé.

## États possibles

- **Analyse de la bibliothèque…** : une actualisation est en cours.
- **Chargement** : aucune liste utilisable n’est encore disponible.
- **Aucun morceau live** : la Bibliothèque est réellement vide ; utilisez **Importer…**.
- **Dossier inaccessible** : l’autorisation Android doit être rétablie.

## Suppression : bien choisir la cible

La suppression peut viser des choses différentes :

- retirer une occurrence d’une playlist ;
- supprimer le morceau live de l’application ;
- supprimer un fichier visible dans le stockage.

Lisez toujours la confirmation. La suppression d’un morceau live retire aussi ses références des playlists, mais ne supprime pas automatiquement vos sauvegardes externes.

La suppression d’un parent Arrangement peut supprimer plusieurs variantes. Le nombre de variantes concernées est indiqué avant confirmation.

## Bonnes pratiques

- Importez les morceaux par l’action visible **Importer…**.
- Effectuez les actions de renommage et de suppression depuis l’application.
- Ne déplacez pas manuellement les données internes de Stage Music Player.
- Sauvegardez la Bibliothèque après une préparation importante.
