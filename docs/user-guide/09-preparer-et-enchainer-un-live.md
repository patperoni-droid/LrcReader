# Préparer et enchaîner une prestation

Stage Music Player sépare la préparation du concert et son exécution. Le téléphone convient aux corrections rapides et aux répétitions ; la tablette offre une vue de scène plus large avec playlist, Lecteur et outils accessibles ensemble.

## Avant la prestation

1. importez tous les morceaux dans la Bibliothèque ;
2. regroupez-les dans une playlist ordonnée ;
3. vérifiez les familles et les variantes ;
4. préparez les niveaux avec LEVELS ;
5. contrôlez les points IN/OUT ;
6. relisez les paroles et les accords ;
7. testez les Arrangements et événements Timeline utilisés ;
8. préparez le Fond sonore ou le DJ si nécessaire ;
9. effectuez une sauvegarde complète ;
10. répétez l’enchaînement sur l’appareil de scène.

## Construire l’ordre de passage

Créez une playlist dédiée au concert. Placez les morceaux dans l’ordre prévu et utilisez des titres explicites pour les variantes. Les groupes et familles peuvent aider à séparer les parties du spectacle ou les versions alternatives.

Un morceau peut être défini comme prochain sans modifier définitivement l’ordre. Vérifiez toujours l’indication du prochain titre avant d’activer un enchaînement automatique.

## Lancer un morceau

1. sélectionnez le titre dans la playlist ;
2. vérifiez le titre affiché dans le Lecteur ;
3. sur tablette, observez la couleur de Play ;
4. appuyez sur Play ;
5. surveillez la progression et le titre suivant.

Un Play jaune signifie que la sélection diffère du morceau actif. L’appui confirme le changement sans qu’une simple sélection ait interrompu le titre en cours.

## Préparer le morceau suivant

Pendant la lecture :

- consultez le prochain titre ;
- sélectionnez-le sans le lancer si vous êtes sur tablette ;
- vérifiez sa variante et son gain ;
- utilisez la Recherche si le programme change ;
- fermez la Recherche pour revenir au contexte de scène.

L’option de retour automatique vers la playlist dix secondes avant la fin peut faciliter cette préparation. Elle se règle dans **Plus**.

## Enchaînement et transitions

Le crossfade manuel peut utiliser une durée de 2, 3, 5, 8, 10 ou 20 secondes. Testez la durée choisie sur les morceaux concernés.

Lorsque vitesse ou pitch ne sont pas neutres, Stage Music Player peut imposer une transition séquentielle plus sûre. Ne supposez donc pas qu’un chevauchement aura lieu sans l’avoir répété.

## Revenir en arrière

La commande de retour de dix secondes sert à reprendre un passage pendant une répétition ou à retrouver rapidement un repère. Évitez de l’utiliser au hasard lorsqu’une Timeline commande du matériel externe : testez auparavant la réaction des événements lors d’un retour temporel.

## Choisir la source audio

Trois sources peuvent intervenir :

- **Player** pour les morceaux principaux ;
- **Fond sonore** pour l’ambiance entre les titres ;
- **DJ** pour une file musicale séparée.

Le démarrage du Player arrête le Fond sonore. Le DJ possède également son propre moteur. Identifiez la source active avant de toucher un niveau ou une commande de transport.

## Réglages conseillés pour la scène

- Choisissez le mode d’ouverture du Lecteur adapté à votre usage.
- Activez uniquement les onglets et indicateurs nécessaires.
- Gardez l’écran alimenté et désactivez les économies d’énergie agressives.
- Placez l’appareil de façon à éviter les touchers accidentels.
- Gardez une solution audio de secours indépendante.

## Contrôle final

Faites une répétition complète dans les conditions les plus proches possibles du concert : même appareil, mêmes câbles, même interface audio et même orientation d’écran. Vérifiez aussi la réception du Deuxième écran et les périphériques MIDI/DMX si vous les utilisez.

## Problèmes courants

### Le mauvais morceau est prêt

N’appuyez pas sur Play. Vérifiez le titre sélectionné, la famille et la variante, puis corrigez la sélection.

### La musique d’ambiance continue ou ne repart pas

Ouvrez le Fond sonore, vérifiez qu’il est activé et que sa source est valide. Son arrêt au démarrage du Player est normal.

### Le niveau change fortement au titre suivant

Arrêtez l’enchaînement automatique, corrigez le gain du morceau puis reprenez. Préparez ensuite tous les niveaux avant la prochaine prestation.
