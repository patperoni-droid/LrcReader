# Sauvegarder et restaurer la Bibliothèque

La sauvegarde complète copie la Bibliothèque dans un dossier externe choisi. Elle protège les morceaux, leurs variantes et l’organisation globale contre la perte ou le remplacement de l’appareil.

Voir ses morceaux dans l’application ne constitue pas une sauvegarde : ces données restent sur le même appareil.

## Contenu d’une sauvegarde complète

La sauvegarde actuelle peut inclure :

- les morceaux et leurs variantes sous forme d’archives `.smp` ;
- les réglages de morceau transportés ;
- les playlists, groupes, ordre, couleurs et titres personnalisés ;
- les textes défilants autonomes ;
- l’état global pris en charge par la version courante.

Une sauvegarde est un dossier contenant plusieurs éléments, pas encore une archive unique. Les notes doivent être partagées séparément par précaution tant que leur couverture n’est pas explicitement garantie.

## Créer une sauvegarde

1. arrêtez la lecture ;
2. ouvrez **Plus** ;
3. choisissez **Sauvegarder ma bibliothèque** ;
4. sélectionnez un dossier externe accessible ;
5. conservez ou modifiez le nom proposé, par exemple `Export_2026-08-12_14-30` ;
6. lancez la sauvegarde ;
7. attendez la confirmation de fin ;
8. ouvrez le dossier avec l’application Fichiers pour vérifier son contenu.

La sauvegarde est prévue hors lecture. Évitez de démarrer un morceau pendant l’export.

## Où conserver la sauvegarde

Utilisez au moins un emplacement distinct de l’appareil de scène : ordinateur, clé compatible, disque externe ou stockage en ligne. Pour un concert important, conservez deux copies.

Ne déplacez pas seulement le dossier interne de l’application : utilisez la commande de sauvegarde afin que l’état global soit exporté avec les morceaux.

## Mettre à jour une sauvegarde existante

Après une sauvegarde réussie, **Mettre à jour la bibliothèque** peut apparaître. Dans la version actuelle, cette action republie surtout les familles de morceaux et leurs variantes.

Elle ne met pas encore à jour de façon complète l’état global, les playlists, les textes défilants ou les suppressions. Pour une sauvegarde fiable après des changements d’organisation, créez une **nouvelle sauvegarde complète**.

## Restaurer une sauvegarde

1. ouvrez **Plus** ;
2. choisissez **Restaurer ma bibliothèque** ;
3. sélectionnez le dossier de sauvegarde ;
4. choisissez le traitement des morceaux ;
5. choisissez séparément le traitement des playlists ;
6. confirmez ;
7. attendez la fin de l’import ;
8. contrôlez Bibliothèque, playlists, variantes et textes défilants.

## Conserver ou remplacer les morceaux

### Conserver les morceaux existants

Les morceaux déjà présents restent prioritaires et les éléments absents peuvent être ajoutés. Choisissez cette option pour compléter un appareil déjà préparé.

### Remplacer les morceaux existants

Les versions transportées par la sauvegarde remplacent les éléments correspondants, puis leurs variantes sont restaurées. Choisissez cette option pour revenir à l’état sauvegardé après avoir vérifié la date du dossier.

## Conserver ou remplacer les playlists

### Conserver les playlists existantes

Les playlists locales sont gardées et les données restaurées sont ajoutées ou rapprochées selon le parcours prévu.

### Remplacer les playlists existantes

Les playlists locales sont supprimées avant l’import de celles de la sauvegarde. Cette option est destructive pour l’organisation créée depuis la sauvegarde.

## Vérifications après restauration

- Lancez plusieurs morceaux, dont une variante.
- Contrôlez l’ordre et les groupes des playlists.
- Ouvrez un texte défilant.
- Vérifiez paroles, niveaux et points IN/OUT.
- Refaites une sauvegarde lorsque l’appareil restauré devient la nouvelle référence.

## Problèmes courants

### Le dossier sélectionné n’est pas reconnu

Choisissez le dossier racine créé par Stage Music Player, pas seulement l’un de ses sous-dossiers.

### Des modifications récentes manquent

La sauvegarde est peut-être antérieure ou a seulement été mise à jour par l’action limitée. Revenez à l’appareil source et créez une nouvelle sauvegarde complète.

### Les playlists locales ont disparu

L’option **Remplacer les playlists existantes** les supprime avant restauration. Utilisez une sauvegarde plus récente ou reconstruisez-les si aucune autre copie n’existe.

### Une archive ancienne ne restaure pas une fonction récente

C’est attendu : une archive ne peut recréer que les données qu’elle transportait au moment de sa création.
