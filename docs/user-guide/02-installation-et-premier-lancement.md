# Installer et préparer l’application

Ce chapitre décrit le premier lancement de la version bêta actuelle de MusiMio sur Android.

## Prérequis

- Un téléphone ou une tablette sous Android 6.0 ou une version plus récente.
- Un espace de stockage suffisant pour vos fichiers audio et leurs copies de travail.
- Un dossier Android accessible en lecture et en écriture, de préférence **Music**.
- Pour l’Accordeur : l’autorisation du microphone sera demandée seulement lors de son utilisation.
- Pour certaines fonctions DJ : Android peut demander l’accès à la musique lors de l’ouverture du mode DJ.

Le canal d’installation peut varier selon la phase de bêta. Utilisez uniquement le lien, le magasin ou le fichier d’installation fourni par le responsable du projet.

## Premier lancement

### 1. Ouvrir l’écran de bienvenue

L’application affiche **Bienvenue dans MusiMio**. Une seule action est nécessaire : **Continuer**.

### 2. Choisir le dossier de travail

Après avoir appuyé sur **Continuer**, MusiMio ouvre le sélecteur de dossiers d’Android. Le dossier **Music** est proposé par défaut lorsque le système le permet.

Vous pouvez :

- confirmer **Music** ;
- naviguer vers un autre dossier accessible ;
- créer au besoin un dossier dédié avant de le sélectionner.

Évitez les emplacements temporaires et les dossiers auxquels Android ne peut pas accorder durablement l’autorisation.

### 3. Confirmer l’autorisation Android

Dans le sélecteur Android :

1. vérifiez le dossier affiché ;
2. appuyez sur **Utiliser ce dossier** ;
3. acceptez la confirmation d’accès si Android en affiche une.

Cette autorisation permet à l’application de préparer son espace de travail. Elle ne lui donne pas un accès sans limite à tout l’appareil.

### 4. Attendre la préparation

MusiMio :

- prépare le dossier de travail ;
- installe automatiquement une Bibliothèque Démo ;
- vérifie que l’espace est utilisable ;
- ouvre ensuite l’application.

Ne fermez pas l’application pendant l’affichage de la roue de progression. Selon l’appareil et le fournisseur de fichiers Android, cette opération peut prendre quelques secondes.

## Ce qui n’est pas demandé au premier lancement

L’application ne vous demande pas immédiatement :

- d’importer votre musique personnelle ;
- de choisir un dossier DJ ;
- d’autoriser le microphone ;
- de choisir un dossier de sauvegarde.

Ces autorisations sont demandées au moment où vous utilisez la fonction correspondante.

## Après l’installation de la Démo

Utilisez la Démo pour vérifier :

1. que la Bibliothèque s’ouvre ;
2. qu’une playlist est disponible ;
3. qu’un morceau peut être sélectionné et lu ;
4. que l’affichage est adapté à votre téléphone ou votre tablette.

Vous pourrez ensuite importer votre musique depuis **Bibliothèque → Importer…**.

## Mode tablette au premier lancement

Sur une tablette détectée comme telle, le mode partagé est activé automatiquement lors d’une installation neuve. La playlist reste à gauche et la destination active s’affiche à droite.

Si vous aviez déjà choisi d’activer ou de désactiver ce mode, MusiMio conserve votre préférence.

## Changer de langue

MusiMio propose le français, l’anglais et l’espagnol.

1. ouvrez **Paramètres / Plus** ;
2. choisissez **Langue** ;
3. sélectionnez **Automatique**, **Français**, **English** ou **Español**.

Le mode automatique suit la langue du système lorsque celle-ci est prise en charge.

## Problèmes courants

### Le dossier Téléchargements est refusé

Sur certains appareils, le fournisseur Android associé à Téléchargements ne permet pas de préparer correctement l’espace de travail. Appuyez sur **Réessayer** et choisissez un dossier standard accessible, de préférence **Music**.

### Le bouton « Utiliser ce dossier » est désactivé

Vous êtes peut-être placé sur un emplacement qu’Android protège. Revenez à un niveau supérieur ou choisissez un autre dossier.

### La préparation semble bloquée

- Patientez quelques secondes sans changer d’application.
- Vérifiez que l’appareil dispose d’espace libre.
- Relancez l’application si Android a fermé le sélecteur de fichiers.
- Si le problème se reproduit, recommencez avec un autre dossier accessible.

### La Démo ne s’installe pas

Vérifiez l’accès au dossier de travail, puis recommencez la configuration. N’effacez pas manuellement des sous-dossiers pendant la préparation.

### Une autorisation a été refusée

Les autorisations DJ ou microphone peuvent être accordées plus tard depuis les réglages Android de l’application. L’accès au dossier de travail doit, lui, être rétabli pour importer et gérer les morceaux.

## Précaution importante : importer n’est pas sauvegarder

Rendre un morceau disponible dans MusiMio ne constitue pas une sauvegarde externe. Lors de l’import, MusiMio prépare une copie de travail interne pour la scène ; le fichier audio source reste séparé et n’est pas modifié.

Prenez rapidement l’habitude de sauvegarder votre environnement MusiMio, puis de mettre cette sauvegarde à jour quand votre Bibliothèque évolue : nouveaux morceaux, playlists, paroles, réglages ou préparation de scène.

Le bon réflexe : votre Bibliothèque MusiMio évolue → votre sauvegarde doit évoluer avec elle.
