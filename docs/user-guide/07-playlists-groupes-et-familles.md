# Organiser ses playlists, groupes et familles

Les playlists organisent les morceaux dans l’ordre d’une répétition ou d’un concert. Elles peuvent contenir des groupes, plusieurs occurrences du même morceau, des familles de versions et des textes défilants.

## Ouvrir les playlists

Touchez **Playlists** dans la navigation principale. Si aucune playlist n’existe, l’application propose d’en créer une.

## Créer une playlist

1. choisissez **Créer une playlist** ou **Nouvelle liste de lecture** ;
2. saisissez un nom ;
3. validez ;
4. ouvrez la nouvelle playlist ;
5. choisissez **Ajouter des morceaux**.

Deux playlists ne peuvent pas porter exactement le même nom dans le même espace.

## Ajouter des morceaux

Vous pouvez ajouter des morceaux :

- depuis le bouton **Ajouter des morceaux** de la playlist ;
- depuis la Bibliothèque avec **Attribuer** ou **Ajouter à une playlist** ;
- par sélection multiple afin de conserver un ordre de préparation.

Une playlist ne duplique pas l’audio. Elle mémorise seulement la présence et la position de chaque morceau.

## Modifier l’ordre

### Glisser-déposer

Maintenez un morceau, puis faites-le glisser vers sa nouvelle position. Attendez que la ligne cible soit visible avant de relâcher.

Le glisser-déposer permet aussi de déplacer un morceau dans ou hors d’un groupe.

### Déplacer vers…

Lorsque le glissement est difficile :

1. ouvrez le menu du morceau ;
2. choisissez **Déplacer vers…** ;
3. sélectionnez une destination, un groupe, **tout en haut** ou **tout en bas** ;
4. vérifiez la nouvelle position.

Cette méthode est recommandée lorsque les conditions de scène rendent le geste imprécis.

## Créer et utiliser des groupes

Les groupes servent de séparateurs visuels : Intro, Set 1, Acoustique, Rappels, etc.

1. ouvrez les actions de la playlist ;
2. insérez un groupe à la position souhaitée ;
3. renommez-le ;
4. déplacez les morceaux dans le groupe ;
5. choisissez éventuellement **Changer la couleur**.

Les groupes peuvent être repliés ou dépliés. Leur couleur sert uniquement à la lecture visuelle et ne modifie pas le son.

Pour un concert, plusieurs playlists courtes peuvent parfois être plus rapides à parcourir qu’une seule grande playlist très groupée.

## Familles de versions

Une famille affiche plusieurs morceaux possibles sous une entrée compacte.

Exemple :

```text
Marina
- version normale
- version courte
- version acoustique
```

Touchez une alternative pour changer le choix actif avant de lancer le morceau. Le Lecteur reçoit toujours le vrai morceau sélectionné.

Les alternatives ne fusionnent pas leur audio et conservent leurs propres paroles et réglages.

## Préparer le prochain morceau

Pour imposer un prochain titre :

1. ouvrez le menu du morceau ;
2. choisissez **Définir comme prochain** ;
3. vérifiez le badge **PROCHAIN** ;
4. utilisez **Annuler PROCHAIN** si vous changez d’avis.

Un seul morceau peut être défini explicitement comme prochain. Ce choix temporaire prend la priorité sur l’ordre normal de la playlist.

## Auto Play

L’action **Auto Play** permet d’enchaîner les morceaux selon l’ordre prévu. Vérifiez toujours le prochain titre affiché dans le Lecteur avant le concert.

À ne pas confondre avec un projet séparé de bouton AUTO du Playback Control tablette : ce projet est suspendu et ne fait pas partie du parcours actuel décrit ici.

## Liste live et groupe rouge

La liste live permet de préparer rapidement une séquence temporaire. Les morceaux du groupe live rouge s’enchaînent dans leur ordre et le prochain titre doit rester visible dans le Lecteur.

Avant de l’utiliser sur scène, testez :

- la création de la liste ;
- l’ordre des morceaux ;
- le titre suivant affiché ;
- la transition à la fin du morceau.

## Titres joués

Les morceaux déjà joués peuvent recevoir un indicateur visuel ou changer de position selon le comportement de la playlist.

Pour préparer la prochaine prestation :

1. ouvrez les actions de la playlist ;
2. choisissez **Réinitialiser** ;
3. confirmez ;
4. vérifiez que l’ordre initial et les groupes sont revenus ;
5. vérifiez que les indicateurs de lecture ont disparu.

## Retirer un morceau d’une playlist

Choisissez **Effacer de la liste** dans le menu de son occurrence. Cette action ne supprime pas le morceau de la Bibliothèque.

Le même morceau peut apparaître plusieurs fois. Chaque occurrence conserve sa position propre.

## Renommer ou supprimer une playlist

Depuis la liste de toutes les playlists :

- utilisez **Renommer la liste** pour modifier son nom ;
- utilisez **Supprimer la liste** pour effacer sa structure.

Supprimer une playlist ne supprime pas les morceaux de la Bibliothèque.

## Importer une playlist

L’action **Importer une playlist** accepte une playlist JSON compatible. Après l’import, MusiMio indique combien de morceaux ont été retrouvés et combien manquent.

Une playlist importée ne peut utiliser correctement un morceau que si celui-ci est déjà présent dans la Bibliothèque avec son identité correspondante.

## Problèmes courants

### « Titre manquant » apparaît

Le morceau référencé n’est peut-être plus présent dans la Bibliothèque ou n’a pas encore été restauré. Actualisez la Bibliothèque, puis vérifiez l’import ou la restauration du morceau.

### Le déplacement ne fonctionne pas

Utilisez **Déplacer vers…**, vérifiez que le groupe n’est pas replié et recommencez sans lecture gestuelle rapide.

### Un morceau ne s’enchaîne pas

Vérifiez le badge prochain, l’ordre du groupe live, le mode Auto Play et la présence réelle du morceau dans la Bibliothèque.

### Une variante ne se lit plus

Son morceau parent a peut-être été supprimé. Une variante Arrangement ne peut pas fonctionner sans l’audio de son parent.
