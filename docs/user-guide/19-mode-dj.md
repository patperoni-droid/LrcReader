# Utiliser le mode DJ

Le mode DJ lit la musique du téléphone ou d’un dossier dédié avec son propre moteur, sa file d’attente et ses commandes de transition. Il sert notamment à diffuser de la musique avant, après ou entre les parties d’un spectacle.

## Afficher l’onglet DJ

Si DJ n’apparaît pas dans la navigation :

1. ouvrez **Plus** ;
2. activez **Afficher le mode DJ** ;
3. revenez à la navigation principale ;
4. ouvrez **DJ**.

## Première ouverture

Android peut demander l’accès à la musique. Autorisez-le si vous souhaitez parcourir les fichiers audio de l’appareil.

Le mode DJ peut utiliser :

- toute la musique accessible sur le téléphone ;
- un dossier choisi manuellement ;
- le dossier dédié `Documents/SPL_Music/DJ`.

Une analyse initiale peut prendre du temps si l’appareil contient beaucoup de fichiers. Évitez de la lancer juste avant la prestation.

## Lire un dossier

1. ouvrez le sélecteur de dossier ;
2. parcourez les sous-dossiers ;
3. choisissez **Lire ce dossier** ou **FOLDER ▶** ;
4. vérifiez le nombre de morceaux ajoutés ;
5. contrôlez la file d’attente.

La Recherche DJ porte sur les sources accessibles au mode choisi. Elle est distincte de la Recherche de la Bibliothèque live.

## File d’attente et Auto

La file d’attente présente les titres préparés pour le DJ. Le mode **Auto** peut les enchaîner. La durée et le résultat du passage entre deux fichiers dépendent de leur contenu et du réglage de crossfade.

La version gratuite peut limiter l’utilisation du mode DJ. Les limites exactes sont indiquées par l’application au moment concerné.

## BUS DJ / MIX AUTO

Le panneau DJ regroupe notamment :

- le niveau DJ ;
- le réglage **X-Fade** ;
- l’action **GO** ;
- la file d’attente ;
- le mode Auto.

Utilisez **DJ LEVEL** ou le fader DJ du Mixage général pour régler cette source. Le gain des morceaux du Player principal n’est pas modifié.

## Coordination avec les autres lecteurs

Player, DJ et Fond sonore sont séparés, mais Stage Music Player coordonne leur priorité pour éviter plusieurs sources dominantes simultanées. Avant de lancer DJ, vérifiez la source active et le niveau du bus correspondant.

## Mettre à jour la musique disponible

Le menu DJ permet de réanalyser le dossier DJ ou la musique du téléphone. Utilisez cette action après avoir ajouté ou retiré des fichiers. Attendez la fin de l’analyse avant de relancer une Recherche.

## Précautions

- Préparez le dossier et la file avant le public.
- Harmonisez les niveaux des fichiers DJ.
- Gardez suffisamment de stockage libre.
- Testez le premier et le dernier titre du dossier.
- N’utilisez pas la réanalyse pendant une lecture importante si elle peut attendre.

## Problèmes courants

### Aucun morceau n’apparaît

Vérifiez l’autorisation d’accès à la musique et le dossier choisi, puis lancez une réanalyse.

### Le dossier DJ n’est pas autorisé

Choisissez **Autoriser le dossier DJ**, puis sélectionnez le dossier demandé par Android. Vous pouvez le réautoriser depuis le menu.

### Une Recherche paraît vide

Attendez la fin de l’analyse et vérifiez si la recherche porte sur toute la musique ou uniquement sur le dossier DJ.

### Le niveau DJ ne correspond pas au Player

Réglez le bus DJ séparément dans le Mixage général. Ne modifiez pas les gains des morceaux live pour compenser le DJ.
