# Préparer les niveaux avec LEVELS

LEVELS permet de préparer à l’oreille le niveau de chaque morceau avant une répétition ou un concert. Le réglage est mémorisé pour le morceau et ne modifie pas son fichier audio d’origine.

## Ouvrir LEVELS

1. ouvrez la **Bibliothèque** ;
2. choisissez l’onglet **LEVELS** ;
3. touchez le morceau que vous souhaitez régler.

La liste affiche le titre et le niveau courant de chaque morceau en décibels.

LEVELS ne propose aucun bouton d’analyse ou de normalisation automatique. Vous écoutez, comparez et choisissez vous-même le niveau adapté.

## Écouter un passage utile

Touchez le bouton de lecture d’un morceau. Choisissez ensuite :

- **Début** ;
- **20 s** ;
- **40 s** ;
- **60 s** ;
- **90 s**.

Le morceau démarre directement au point choisi. Cette fonction permet d’atteindre rapidement un refrain ou un passage fort sans attendre une longue introduction.

Si le morceau est déjà en lecture, la commande l’arrête.

## Régler le LEVEL

1. touchez la ligne du morceau afin de le sélectionner ;
2. ouvrez le tiroir de niveau situé sur le côté droit ;
3. déplacez le fader pendant l’écoute ;
4. comparez avec un morceau de référence ;
5. passez au morceau suivant lorsque le résultat vous convient.

La plage de réglage active va de `-24 dB` à `+6 dB`.

Le niveau est immédiatement audible et mémorisé pour le morceau. Il sera réutilisé lorsque vous lancerez ce morceau depuis la Bibliothèque, une playlist ou le Lecteur.

## Utiliser le Playback Control

Le Playback Control affiché en bas de LEVELS permet de :

- lancer ou mettre en pause le morceau actif ;
- suivre et déplacer la position de lecture ;
- revenir au début ;
- voir le niveau courant ;
- effectuer de petits ajustements de niveau.

Sélectionner un autre morceau dans la liste ne doit pas interrompre automatiquement celui qui joue. Vérifiez toujours le titre ciblé avant d’appuyer sur Play.

## Méthode conseillée

1. choisissez un morceau de référence correctement équilibré ;
2. conservez le même volume général et le même système d’écoute ;
3. écoutez un passage représentatif de chaque titre ;
4. ajustez son LEVEL à l’oreille ;
5. comparez plusieurs morceaux deux par deux ;
6. testez ensuite la playlist complète dans son ordre réel.

L’objectif est d’éviter les écarts gênants, pas d’aplatir la dynamique de tous les morceaux.

## Précautions

- Un niveau positif élevé peut provoquer de la saturation.
- Une introduction calme n’est pas toujours représentative du morceau.
- Deux morceaux de styles différents ne doivent pas forcément sembler aussi forts.
- Préparez les niveaux avant le concert et contrôlez-les sur le système réellement utilisé.

## Problèmes courants

### Le mauvais morceau est réglé

Touchez sa ligne et vérifiez son titre avant de déplacer le fader.

### Le passage choisi n’est pas représentatif

Arrêtez la lecture, puis relancez le morceau depuis un autre point de démarrage rapide.

### Le son sature

Réduisez le LEVEL, vérifiez le gain du morceau et refaites un essai au volume de scène.

### Le niveau ne semble pas mémorisé

Quittez puis rouvrez LEVELS et vérifiez la valeur affichée. Contrôlez ensuite le même morceau dans le Lecteur.
