# Utiliser l’Accordeur

L’Accordeur utilise le microphone de l’appareil pour détecter la note jouée, sa fréquence et son écart en cents.

## Ouvrir l’Accordeur

Ouvrez **Accordeur** depuis **Plus** ou depuis les raccourcis de scène sur tablette. La première utilisation demande l’autorisation d’enregistrer le son avec le microphone.

## Autoriser le microphone

1. ouvrez l’Accordeur ;
2. appuyez sur **Autoriser le micro** si nécessaire ;
3. acceptez la demande Android ;
4. jouez une note près du microphone.

L’analyse démarre quand l’écran est ouvert et l’autorisation accordée. Elle s’arrête lorsque vous quittez l’Accordeur.

## Lire l’affichage

L’écran indique :

- le nom de la note détectée ;
- sa fréquence en hertz ;
- son écart en cents ;
- une aiguille centrée lorsque la note est juste ;
- **IN TUNE** et une couleur jaune lorsque l’accord est considéré comme correct ;
- le niveau d’entrée du microphone.

Une valeur négative indique une note trop basse ; une valeur positive, une note trop haute. Approchez progressivement l’aiguille du centre.

## Accorder un instrument

1. placez-vous dans un environnement aussi calme que possible ;
2. rapprochez l’instrument de l’appareil ;
3. jouez une seule note et laissez-la sonner ;
4. vérifiez le nom détecté ;
5. ajustez la corde ou l’instrument ;
6. recommencez jusqu’à l’affichage **IN TUNE** ;
7. contrôlez une seconde fois après avoir accordé les autres cordes.

## Utiliser l’Accordeur pendant une lecture

Le Playback Control principal peut rester visible en bas de l’écran. L’Accordeur écoute néanmoins le microphone : la musique diffusée par les haut-parleurs peut perturber la détection. Mettez la lecture en pause ou utilisez un casque pour obtenir un résultat fiable.

## Précautions

- Le microphone sert uniquement à l’analyse pendant l’ouverture de l’Accordeur.
- Les bruits ambiants et d’autres instruments peuvent fausser la note détectée.
- Le niveau d’entrée est un indicateur, pas un réglage de gain du microphone.
- Accordez l’instrument à sa température d’utilisation, puis vérifiez-le sur scène.

## Problèmes courants

### « Micro non autorisé » apparaît

Appuyez sur **Autoriser le micro**. Si Android ne repropose plus la demande, ouvrez les paramètres système de l’application et accordez l’autorisation Microphone.

### « En attente du signal » reste affiché

Jouez plus près du microphone, augmentez légèrement le volume acoustique et vérifiez que l’orifice du micro n’est pas couvert.

### La note change sans arrêt

Isolez une seule corde, étouffez les autres et éloignez l’appareil des enceintes. Attendez que l’attaque initiale soit passée.

### L’aiguille paraît instable

Maintenez la note, évitez le vibrato et réduisez les bruits ambiants. Les notes très aiguës ou certains timbres peuvent demander davantage de stabilité.
