# Découvrir Stage Music Player

Stage Music Player réunit dans une même application la préparation des morceaux, les playlists, la lecture audio, les paroles et plusieurs outils conçus pour la scène.

## Ce que permet l’application

Vous pouvez notamment :

- importer vos fichiers audio et vos fichiers `.smp` ;
- regrouper l’audio, les paroles, les accords et les réglages d’un morceau ;
- préparer plusieurs playlists et les modifier pendant une prestation ;
- afficher des paroles ou des accords synchronisés avec la musique ;
- créer des textes défilants sans audio ;
- régler le niveau, la vitesse, la hauteur et les points de début ou de fin d’un morceau ;
- créer des versions Arrangement sans modifier l’audio d’origine ;
- partager un morceau et ses données au format SMP ;
- sauvegarder et restaurer la Bibliothèque ;
- utiliser un téléphone, une tablette ou un deuxième appareil d’affichage.

## Le principe d’un morceau live

Dans Stage Music Player, un morceau ne se limite pas à son fichier audio. Il peut aussi contenir :

- des paroles ;
- des accords ;
- des couleurs de lignes ;
- des réglages de lecture ;
- des notes et des repères temporels ;
- un Arrangement et ses variantes.

Après l’import, Stage Music Player conserve une copie de travail interne. Modifier le titre affiché, les paroles ou les réglages ne modifie pas votre fichier audio d’origine.

## Démarrage rapide

### 1. Préparer l’espace de travail

Au premier lancement :

1. appuyez sur **Continuer** ;
2. dans le sélecteur Android, choisissez un dossier accessible, généralement **Music** ;
3. confirmez avec **Utiliser ce dossier** ;
4. attendez la fin de la préparation et de l’installation de la Bibliothèque Démo.

Pour plus de détails, consultez [Installer et préparer l’application](02-installation-et-premier-lancement.md).

### 2. Découvrir la Démo

La Démo permet de parcourir l’application avant d’importer vos propres morceaux :

1. ouvrez **Playlists** ;
2. choisissez la playlist de démonstration ;
3. touchez un morceau ;
4. utilisez **Play**, **Pause** et le retour au début ;
5. ouvrez **Paroles** ou **Accords** si ces contenus sont disponibles.

### 3. Importer un premier morceau

1. ouvrez **Bibliothèque** ;
2. appuyez sur **Importer…** ;
3. choisissez **Importer un morceau audio** ;
4. sélectionnez le fichier avec Android ;
5. attendez que le morceau apparaisse dans la Bibliothèque.

Vous pouvez aussi choisir **Importer un fichier SMP** si le morceau vous a été transmis depuis Stage Music Player.

### 4. Créer une playlist

1. ouvrez **Playlists** ;
2. créez une nouvelle playlist ;
3. ajoutez-y des morceaux depuis la Bibliothèque ;
4. placez-les dans l’ordre souhaité ;
5. utilisez les groupes si vous souhaitez séparer les parties du concert.

### 5. Préparer le prochain morceau

Pendant la lecture, vous pouvez sélectionner un autre morceau sans nécessairement l’interrompre immédiatement. Sur tablette, le bouton **Play** devient jaune lorsque le morceau sélectionné diffère du morceau actif. Appuyez sur ce bouton jaune pour confirmer le changement.

## Téléphone ou tablette ?

Le téléphone convient particulièrement à :

- l’import et la préparation ;
- l’édition des paroles ;
- les répétitions ;
- l’utilisation comme appareil de secours.

La tablette offre un cockpit de scène plus large :

- playlist visible à gauche ;
- paroles ou outil actif à droite ;
- commandes de lecture toujours accessibles ;
- passage rapide entre Bibliothèque, Lecteur, Fond sonore et autres outils.

Les données musicales et les règles de lecture restent les mêmes sur les deux appareils.

## Avant une première prestation

- Importez tous les morceaux à l’avance.
- Ouvrez chaque morceau au moins une fois pendant la préparation.
- Vérifiez les paroles, les accords, le niveau et les points IN/OUT.
- Testez l’ordre des playlists et les transitions sur l’appareil réel.
- Désactivez les économies d’énergie susceptibles d’interrompre l’application.
- Effectuez une sauvegarde complète sur un emplacement distinct de l’appareil.

## Si quelque chose ne fonctionne pas

- **Le morceau n’apparaît pas** : revenez dans la Bibliothèque et relancez son actualisation.
- **Android refuse le dossier** : choisissez un dossier standard accessible, comme Music, puis confirmez l’autorisation.
- **Aucune parole n’est affichée** : le morceau ne possède peut-être pas encore de paroles synchronisées.
- **Une fonction n’est pas visible** : certaines fonctions dépendent de l’édition de l’application ou d’un réglage d’affichage.
