# Utiliser le Fond sonore

Le Fond sonore diffuse une ambiance entre les morceaux principaux. Il utilise un lecteur séparé et s’efface automatiquement lorsque le Player démarre.

## Ouvrir et activer le Fond sonore

1. ouvrez **Fond sonore** depuis la navigation ou les raccourcis de scène ;
2. choisissez une source ;
3. activez **Activer le fond sonore** ;
4. réglez son volume ;
5. utilisez Play pour tester l’ambiance.

Si le morceau principal est déjà en lecture, l’activation prépare le Fond sonore sans le rendre prioritaire. Il pourra démarrer lorsque le Player sera inactif.

## Choisir la source

Deux sources sont prévues :

- **Ambiance par défaut** : deux nappes incluses dans l’application ;
- **Dossier personnalisé** : fichiers audio choisis par l’utilisateur.

Le dossier personnalisé peut être réservé à la version Pro. L’application peut demander l’autorisation d’accéder au dossier DJ ou au dossier choisi.

## Commandes locales

Le lecteur du Fond sonore propose :

- précédent ;
- Play/Pause ;
- suivant ;
- réglage du volume.

Ces commandes ne déplacent pas le morceau principal. Vérifiez le titre ou le nom de l’ambiance affiché avant d’agir.

## Priorité avec le Player

Lorsque le Player démarre, le Fond sonore s’arrête automatiquement. Après l’arrêt du Player, il peut reprendre si son activation et sa configuration le permettent.

Ce comportement évite que l’ambiance se superpose involontairement au morceau de scène. Testez toutefois le passage Player/Fond sonore avec les fichiers réellement utilisés.

## Préparer une ambiance personnalisée

1. placez les fichiers dans un dossier accessible à l’application ;
2. ouvrez **Source du fond sonore** ;
3. choisissez **Dossier personnalisé** ;
4. autorisez le dossier demandé ;
5. sélectionnez le dossier ou sous-dossier ;
6. testez précédent, suivant et reprise après le Player.

Selon le parcours affiché, les fichiers personnalisés peuvent devoir se trouver sous `Documents/SPL_Music/DJ`.

## Régler le niveau

Le niveau local agit sur le Fond sonore. Le Mixage général possède aussi un fader **Fond sonore**. Évitez de pousser simultanément les deux réglages au maximum.

Une ambiance doit rester moins présente que les morceaux principaux. Réglez-la avec le système de sonorisation utilisé sur scène.

## Problèmes courants

### Aucun son n’est sélectionné

Choisissez l’une des ambiances incluses ou autorisez un dossier personnalisé contenant des fichiers audio compatibles.

### Le dossier paraît vide

Vérifiez l’autorisation Android et l’emplacement des fichiers. Si une analyse DJ est en cours, attendez sa fin avant de conclure que le dossier est vide.

### L’ambiance s’arrête dès qu’un morceau commence

C’est le comportement normal : le Player principal est prioritaire.

### Le Fond sonore est trop fort

Réduisez son volume local puis son fader dans le Mixage général. Contrôlez aussi le volume physique de l’appareil.
